3.try and catch: we use them to can control the procees and if an error happened we can control it by them

7.catch: it take the error object and displays an error message and the error we write it or any other error

8.interface: we use more with the objects or api responser or props (it extends)

9.type: we use it with the union types (string | number "this or this") , can also be used with objects
